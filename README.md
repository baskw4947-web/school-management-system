# School Management System

A comprehensive School Management System developed using PHP, MySQLi, HTML5, CSS3, Bootstrap and JavaScript, with an Electron JS desktop application.

The system is designed to simplify school administration, student management, academic activities and financial operations.

## Main Features

### 1. Student Management
- Student registration and profiles
- Student admission numbers and LIN numbers
- Student photographs
- Guardian information
- Class and section assignment
- Student searching and filtering
- Student reports

### 2. Teacher Management
- Teacher registration and profiles
- Teacher class assignments
- Subject assignments
- Teacher timetables
- Teacher reports

### 3. Academic Management
- Class management
- Subject management
- Academic years and terms
- Class timetables
- Student assessment and results
- Report card generation
- O-Level and A-Level report cards

### 4. Bursar and Financial Management
- School fee structures
- Student fee payments
- Payment tracking
- Income and expenditure records
- Financial reports
- Teacher salary payments

### 5. User Management
- Administrator
- Assistant Administrator
- Teacher
- Bursar
- Role-based access control
- User registration and account management

### 6. User Registration Expiry and Renewal
- Default registration expiry of 30 days
- Account expiry management
- Account renewal functionality
- Default administrator account exemption (ID 1, username admin)

### 7. Other Modules
- Library management
- School assets management
- School projects management
- Other staff management
- Biometric integration support

## Technologies Used

- PHP 8.3
- MySQL / MariaDB
- MySQLi
- HTML5
- CSS3
- Bootstrap 4
- JavaScript
- Electron JS

## Installation

1. Download or clone the project.
2. Extract the project files.
3. Create a MySQL database.
4. Import the supplied database schema.
5. Configure database connection settings.
6. Configure the PHP environment.
7. Open the application through your local server.

## Default Administrator

The system includes a default administrator account.

For security reasons, administrator login credentials should be configured privately during installation and should not be published in this repository.
